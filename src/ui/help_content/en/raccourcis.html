Keyboard shortcuts

Global

ShortcutAction
F9Show / hide the sidebar
F11Toggle full screen
F5Start the slideshow
Ctrl+FOpen the advanced search
EscLeave the viewer / full screen

Photo grid

ShortcutAction
DelDelete the selected photos (with confirmation) — in an album: remove from the album, without touching the files
Ctrl+ASelect everything
Ctrl+SSave the processed image to disk (a single photo selected)
Double-clickOpen in the viewer

Timeline mode (filmstrip)

ShortcutAction
◀ ▶Move by one photo
▲ ▼Move by 3 photos
WheelScrolling with inertia
Scroll bar (on the right)Quick navigation along the timeline
DelDelete the centre photo (or the selection)

Viewer

ShortcutAction
◀ ▶ or WheelPrevious / next photo
Ctrl+WheelZoom in / out
Double-clickZoom 1:1 ↔ automatic fit
FFit to the window
ZZoom 100 %
IShow / hide the EXIF panel
1 … 5Rate the photo (1 to 5 stars)
0Remove the rating
Ctrl+ZUndo the last edit
Ctrl+YRedo the undone edit
Ctrl+SSave the processed image to disk
EscBack to the grid

Note: there is no dedicated keyboard shortcut for favourites any more — use the ♡ button in the toolbar or the context menu.

Slideshow

▶ ▼Newer photo

Crop mode

ShortcutAction

EscCancel the crop

Annotation mode

ShortcutAction
