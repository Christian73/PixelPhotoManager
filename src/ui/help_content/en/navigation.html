Browsing the library

Sidebar — Folders

  • Click a folder to show its contents in the grid.
  • Click the ▶ arrow to expand the subfolders.
  • Tools › Folders… — advanced management: status, number of files, forced rescan.

Right-click on a folder:

ActionEffect
Scan nowForces a rescan to pick up new files
Stop watching this folderRemoves the folder from the library (the files stay on the disk)
Create a subfolder…Creates a subfolder on the disk
Rename…Renames the folder on the disk and updates the catalogue
Move to…Moves the whole folder to another location
Open in File ExplorerReveals the folder in Windows File Explorer
Delete the folder…Sends the folder and everything in it to the Windows recycle bin (recoverable)

Sidebar — Albums

Special albums (built in, not editable):

AlbumContents
★ TimelineEvery photo in chronological ribbon mode
♡ FavouritesPhotos marked with a heart (♡ button in the viewer, or context menu)
▶ VideosEvery video in the library
★ By ratingCollapsible — click the header to show the photos rated ≥ 1 star, or one of the 5 levels (5★ to 1★) to show the photos with at least that rating (see “Rating” below)
🏷 By keywordCollapsible — one entry per existing keyword; click a keyword to show the photos carrying it, or the header (with text in the filter box) for a free search
🔍 By file namePhotos whose name contains the text typed in the sidebar filter box
  • Personal albums — created with the + button in the Albums header.
  • Click an album to show its contents in the grid.
  • In a personal album, Del or right-click › Remove from the album takes the photo out of the album without touching the file or the catalogue.

Sidebar — Filtering

  • The input box at the top of the sidebar filters both the folders and the people in real time.
  • The 🔍 By file name album uses that same text to show in the grid every photo whose file name matches — type a word in the box, then click that album.
  • The 🏷 By keyword album uses the same text to show every photo carrying that exact keyword (see “Keywords” below).

Sidebar — People

  • Shows the people identified by the face analysis.
  • An orange badge between the thumbnail and the name gives the number of pending suggestions.
  • Click a person to see their confirmed faces and their suggestions.

Right-click on a person:

ActionEffect
Rename…Changes the name throughout the library
Merge with…Merges this person's faces with another person's
Clear the name…Removes the name — the faces go back to being anonymous groups

Search

  • The filter box at the top of the sidebar (see “Sidebar — Filtering” above) filters folders and people instantly, and feeds the 🔍 By file name and 🏷 By keyword albums.
  • Filtering happens as you type. Use the ✕ button in the box to go back to the full listing.

Advanced search

  • Menu File › Advanced search… (Ctrl+F), or the magnifier button next to the sidebar filter box.
  • Combines several criteria at once: date range, camera, person, folder, minimum rating, keywords, favourites, media type (photo/video).
  • The results appear in the grid like any other view (the context shown at the top reads “Advanced search”).

Timeline mode (ribbon)

  • 5 rows of lenticular sizes — the central row is the largest.
  • Move with the wheel (with inertia), the arrow keys or the scroll bar on the right.
  • The photo at the centre of the ribbon is the one the slideshow starts from.

Moving around in the viewer

  • ← ↑ or the wheel: previous photo.
  • → ↓ or the wheel: next photo.
  • Double-click: 1:1 zoom ↔ fit to window.
  • Ctrl+wheel: zoom in / out.
  • Esc or ✕: back to the grid.
  • F11: full screen.
  • Right-click in the viewer › Show the folder in the grid: goes back to the grid showing the folder of the current photo, with it selected.

Rating (★)

  • In the viewer: 5 clickable stars in the toolbar, or keys 1 to 5. Clicking the star that is already selected (or pressing 0) clears the rating.
  • In the grid: right-click one or more photos › Rate.
  • A star badge (e.g. “★★★”) appears at the bottom left of a rated thumbnail.
  • The ★ By rating album in the sidebar is collapsible: expand it to pick a level (5★ to 1★) and show the photos rated at least that many stars; the header alone shows every photo rated ≥ 1 star. A filter on an exact minimum rating is also available through the Advanced search.

Keywords

  • Right-click one or more photos (grid or viewer) › Keywords… opens an editing dialog with auto-completion on the keywords already used in the library.
  • The assigned keywords are shown at the top of the viewer's EXIF panel (separate from the file's own EXIF keywords, which stay visible further down).
  • The 🏷 By keyword album in the sidebar shows every photo carrying the keyword typed in the filter box (exact match, not a substring).
  • A forced rescan of a folder (Tools › Folders…) never changes the keywords or the ratings already assigned.

Deleting files

  • In the grid: select, then press Del.
  • In timeline mode with nothing selected: Del deletes the central photo.
  • In the viewer: the 🗑 button in the toolbar.
  • Files go to the Windows recycle bin (recoverable from there), never permanently erased. A confirmation is asked for. If the recycle bin is unavailable (network drive, volume without a recycle bin…), the file is not deleted and a message says so.
  • Deletion runs in the background: the interface stays usable and the status bar shows the progress (“Deleting… n/total”) on large selections.
  • Inside an album: Del (grid or viewer) removes the photo from the album instead of deleting the file — the file and the photo stay intact in their folder. To really delete the file, go through the view of its folder.

Moving photos

  • Select one or more photos in the grid, then drag them onto a folder in the sidebar.
  • The file is moved on the disk and the catalogue is updated automatically.
